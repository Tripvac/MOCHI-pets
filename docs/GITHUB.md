# Публикация исходников на GitHub

Целевой публичный репозиторий: [Tripvac/MOCHI-pets](https://github.com/Tripvac/MOCHI-pets).

Подготовленная копия содержит исходники, графику, звук, тесты и документацию. В неё не входят `node_modules`, `dist`, локальные дома, параметры хостинга исходного предпросмотра и история рабочего репозитория. README находится в корне.

## Windows: готовый файл публикации

1. Установите [Git for Windows](https://git-scm.com/downloads/win), если Git ещё не установлен.
2. Полностью распакуйте `MOCHI_GitHub.zip`.
3. В папке MOCHI запустите **`PUBLISH_GITHUB_WINDOWS.bat`**.
4. Если Git откроет окно входа, войдите в GitHub как **Tripvac**.

Файл создаёт локальный Git-репозиторий, добавляет remote `mochi-github` на `Tripvac/MOCHI-pets`, коммитит подготовленные файлы и отправляет `HEAD` в `main`. Существующий `origin` не меняется. Если имя и email автора коммитов отсутствуют, используются Tripvac и GitHub noreply-адрес этого аккаунта. Публикация исходников не требует npm, Node.js или запуска игры.

Ключи и токены в чат передавать не нужно: вход выполняется на вашем компьютере. При ошибке окно остаётся открытым, сообщение Git видно над строкой остановки. Принудительная перезапись истории не используется. Если на GitHub уже появились коммиты, обычный push может быть отклонён; сначала нужно согласовать истории.

Этот `.bat` подготовлен для Windows; исполнение на физическом Windows-компьютере здесь не проверялось. Публикация считается завершённой только после успешного push и появления файлов в репозитории.

## Через терминал

В распакованной папке без Git-истории:

```bash
git init -b main
git add .
git commit -m "Publish MOCHI 9 with full documentation"
git remote add mochi-github https://github.com/Tripvac/MOCHI-pets.git
git push -u mochi-github HEAD:main
```

Если Git попросит имя и email автора, настройте их обычным способом через `git config`. Для входа используйте собственный аккаунт GitHub и стандартный Git Credential Manager либо уже настроенный способ авторизации. Пароли и токены не должны попадать в файлы проекта или текст коммита.

Перед отправкой можно проверить `git status` и `git diff --cached --stat`. В коммитах не должно быть `.env`, `.mochi-data`, ключей, токенов и `node_modules`. Готовый `MOCHI-play.html` создаётся командой `npm run standalone`; для его распространения удобнее отдельный GitHub Release.

GitHub хранит код. Размещение игры и общего сервера описано в [DEPLOYMENT.md](DEPLOYMENT.md).
