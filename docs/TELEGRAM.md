# Подключение к Telegram на iPhone

Клиент уже использует официальный Telegram Mini Apps SDK. Бот, токен и сервер не создавались и в исходники не включены.

1. Соберите приложение командой `npm run build` либо возьмите готовую папку `dist`.
2. Разместите **содержимое** `dist` в корне доступного HTTPS-сайта. Домен должен открываться в Telegram без авторизации ChatGPT. В этой сборке адреса ресурсов начинаются с `/`, поэтому размещайте её в корне домена.
3. В официальном [@BotFather](https://t.me/BotFather) создайте или выберите своего бота. В настройках Mini App укажите HTTPS-адрес приложения. Настройте кнопку меню приложения. Точные названия пунктов зависят от версии BotFather.
4. Откройте своего бота на iPhone и нажмите кнопку приложения. Клиент вызовет `ready()` и `expand()`, применит безопасные отступы и включит тактильный отклик на поддерживаемом клиенте. Переход в fullscreen принудительно не запрашивается.
5. Проверьте маленький и большой текст, клавиатуру при вводе имени, сворачивание и возврат, покупки, сохранение и системную кнопку «Назад». Проверьте обе комнаты, ночь и дождь, все четыре игры.
6. До запуска для других пользователей подключите сервер по `INTEGRATION.md`. В сборке есть локальный режим и Node-сервер общего дома для LAN. Статическая папка dist не содержит серверного API. Для публичной версии нужны проверка Telegram initData и авторизация участников.

Для кнопки меню через собственный сервер Bot API используется `setChatMenuButton` с `menu_button.type = "web_app"` и полем `web_app.url`, равным вашему HTTPS-адресу. Токен бота храните только на сервере. Для фронтенда он не нужен.

Приватный предпросмотр не является публичным адресом готового Telegram-бота. Авторизация Telegram и проверка `initData` на сервере — отдельный этап; `initDataUnsafe` не используется для доверенной идентификации.

Официальная документация: https://core.telegram.org/bots/webapps
