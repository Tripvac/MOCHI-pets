# MOCHI на главном экране iPhone

Это настоящий виджет iOS через приложение Scriptable. Для установки не нужны Mac, Xcode или сборка собственного iOS-приложения. Сам файл не устанавливает виджет без Scriptable.

## Установить питомца

1. Установи Scriptable из App Store: https://apps.apple.com/ru/app/scriptable/id1405459188
2. Скачай `public/widgets/MOCHI.scriptable`. В «Файлах» выбери «Поделиться» → Scriptable и добавь скрипт MOCHI. Если импорт этого формата недоступен, скопируй `public/widgets/MOCHI.js` в iCloud Drive → Scriptable: он появится в приложении.
3. Открой MOCHI в Scriptable. Через «Выбрать питомца» можно выбрать Пушина, Пико, таксу, кролика, Максвелла, капибару или Чимса. Посмотри результат в предпросмотре.
4. Удерживай пустое место на главном экране iPhone, добавь виджет Scriptable маленького или среднего размера. Удерживай добавленный виджет → «Изменить виджет» → в поле Script выбери MOCHI.

По умолчанию виджет показывает крупного питомца. Он работает без сети: все 14 портретов — семь питомцев с открытыми и закрытыми глазами — включены в файл.

## Показать потребности

В настройках виджета поле Parameter можно оставить пустым или указать:

| Параметр | Что увидишь |
| --- | --- |
| `pet` | Крупный питомец |
| `needs` | Еда, сон и игры |
| `both` | Питомец и потребности; выбирай средний размер |
| `pusheen` | Пушин независимо от выбранного друга в игре |
| `hamster` | Пико |
| `dog` | Такса Пончик |
| `rabbit` | Кролик Луна |
| `cat` | Максвелл |
| `capybara` | Капибара Капи |
| `cheems` | Чимс |

Чтобы получить реальные показатели:

1. В игре открой настройки → «Виджет на iPhone» → «Передать потребности».
2. Если данные скопированы, открой Scriptable → MOCHI → «Импортировать из буфера». Если iPhone предложил поделиться файлом, передай его Scriptable и выбери MOCHI.
3. Поставь параметр `needs` или `both`. Портрет с одеждой, имя и показатели берутся из переданного сохранения. Для сна используется портрет с закрытыми глазами.

**Передача из игры пока ручная.** После кормления или других действий передай данные повторно, чтобы виджет знал о них. Автоматической связи с сохранением Telegram в этой версии нет. Для неё нужен общий сервер.

После передачи виджет может показывать изменение потребностей на протяжении 48 часов. Прогноз подготовлен теми же правилами, что и сама игра. После истечения этого срока виджет попросит обновить данные и покажет прочерки вместо устаревших процентов. Без данных проценты также не выдумываются.

iOS определяет время обновления виджетов; немедленная перерисовка после передачи не гарантируется. Виджет статический: звуки и постоянные анимации остаются в игре. Нажатие на виджет открывает размещённую версию MOCHI.

## Для разработчика

- `phone-widget/src/main.mjs` — интерфейс и настройки Scriptable.
- `phone-widget/src/core.mjs` — проверка импорта, выбор питомца и актуального кадра потребностей.
- `shared/widget.mjs` — прогноз из существующих правил игры, без изменения сохранения.
- `src/widgetExport.ts` — подготовка портретов и данных из игры.
- `npm run widget` — сборка автономных файлов `.js` и `.scriptable` из включённых портретов. Для этого нужны зависимости проекта; при работе на телефоне сборка не нужна.

Файлы виджета не выполняют сетевые запросы и не читают буфер обмена в фоне. Буфер читается только после выбора «Импортировать из буфера». Данные хранятся локально в Scriptable.

Проверено выполнение готового скрипта с моделями API Scriptable, все семь питомцев в двух размерах, отсутствие выдуманных процентов, импорт, устаревание данных и соответствие прогнозов правилам игры. Проверка на физическом iPhone пока не выполнена.

Официальная инструкция Scriptable: https://scriptable.app/docs/first-widget/
